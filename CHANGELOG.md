# Changelog

## 1.1.0

- Renamed the project and display name to **AI bot diary**.
- Changed the AstrBot plugin ID to `astrbot_plugin_ai_diary`.
- Updated English and Chinese installation, configuration and migration docs.
- Added direct ZIP download instructions.

## 1.0.0

- Initial public release.
- Per-session daily diary storage.
- Daily writing at a configurable time.
- Recall of up to two recent entries.
- Privacy scrubbing for phone numbers, ID numbers and passwords.
- Admin command `/写日记`.
- English and Chinese documentation.
